# Books Data Pipeline — Scrape · Analyze · Visualize

A beginner-friendly end-to-end data pipeline built with pure Python. It scrapes book data from the web, performs exploratory data analysis, and produces clear visualizations — all without pandas, numpy, or any heavy libraries.

The three scripts are designed to run in sequence: the scraper feeds the analyzer, which feeds the visualizer.

---

## Project Structure

```
books-pipeline/
├── books_scraper.py          # Step 1 — Scrape books from the web
├── eda_analysis.py           # Step 2 — Explore and analyze the dataset
├── data_visualization.py     # Step 3 — Visualize insights as charts
├── books_data.csv            # Generated by books_scraper.py
├── eda_charts.png            # Generated by eda_analysis.py
├── visualization_charts.png  # Generated by data_visualization.py
└── README.md                 # This file
```

## Technologies Used

| Library | Role |
|---|---|
| `requests` | Sending HTTP requests to the target website |
| `bs4` (BeautifulSoup) | Parsing and extracting HTML content |
| `csv` | Reading and writing structured data |
| `matplotlib` | Creating bar charts and pie charts |

No pandas, numpy, seaborn, or Selenium — just clean, readable Python.

---

## How to Run

### 1. Install dependencies
```bash
pip install requests beautifulsoup4 matplotlib
```

### 2. Step 1 — Scrape the data
```bash
python books_scraper.py
```
Scrapes the first 3 pages of [books.toscrape.com](http://books.toscrape.com) and saves **60 books** to `books_data.csv`.

### 3. Step 2 — Analyze the data
```bash
python eda_analysis.py
```
Reads `books_data.csv`, prints summary statistics, detects data issues, and saves `eda_charts.png`.

### 4. Step 3 — Visualize the data
```bash
python data_visualization.py
```
Reads `books_data.csv`, generates 3 charts, prints a data story, and saves `visualization_charts.png`.

> Run the scripts in order — Steps 2 and 3 both depend on `books_data.csv` from Step 1.

---

## What Each Script Does

### `books_scraper.py` — Web Scraper
- Fetches pages 1–3 from `books.toscrape.com`
- Extracts: **title, price, star rating, availability, product link**
- Saves results to `books_data.csv`

### `eda_analysis.py` — Exploratory Data Analysis
Answers 4 key questions about the dataset:
- What is the average, min, and max price?
- Which star rating appears most often?
- How are books distributed by availability?
- Does rating correlate with price?

Also detects potential data issues (missing fields, small sample size, encoding quirks).

### `data_visualization.py` — Data Visualization
Produces 3 charts saved to `visualization_charts.png`:

| Chart | Type | What It Shows |
|---|---|---|
| Rating Distribution | Bar chart | How books are spread across 1★–5★ |
| Average Price by Rating | Bar chart | Whether price varies with rating |
| Availability Distribution | Pie chart | In stock vs unavailable breakdown |

---

## Key Findings

- The dataset contains **60 books** across 5 star ratings
- Average book price is **£35.00** (range: £12.84 – £57.31)
- **1★** is the most common rating; **2★** is the least common
- Prices are roughly uniform across all ratings — no strong correlation
- **100%** of books in the sample are listed as in stock
